Web App Concept

Limelight Cinema

Overview

Limelight Cinema is a college project I built to simulate a booking platform for a regional cinema group. It links a responsive frontend with a secure PHP and MySQL backend. The main goal was to handle different user journeys, ensuring junior members, adult customers and admin staff each get the right access and features.

Role & Tech Stack

  • UI/UX Design & Responsive Layouts
  • Front-end Engineering (HTML/CSS/JS)
  • Back-end Development (PHP/MySQL)
  • Role-Based Authentication & CRUD
