React & Firebase App

crost

Overview

crost is a minimalist task manager app designed to help users focus on what matters. Built as an accessible, mobile-first web application, it leverages React for a seamless user interface and Firebase for real-time data synchronization, ensuring tasks are always up-to-date across sessions.

Role & Tech Stack

  • Front-end Engineering (React.js)
  • Real-time Database (Firebase)
  • Mobile-First & Accessible UI Design
  • State Management & Data Sync
