Overview

Bike King Borders is a college project where I redesigned a local bike shop's outdated website to give it a fresh, modern look. I reviewed the original interface to fix frustrating user experience issues like broken links, hidden buttons and messy layouts. My main goal was to bring the site up to 2026 web standards and make it much easier for customers to navigate.

Role & Tech Stack

  • UI/UX Redesign & Brand Modernisation
  • Front-end Engineering (HTML5/CSS3/JS)
  • CSS Architecture (Custom Properties & Design Systems)
  • Responsive Optimisation & Accessibility

Key Improvements

  • Created a consistent visual style across the whole site using a unified design system.
  • Built a modern glassmorphism navigation bar with adaptive background blur.
  • Upgraded the fonts to use clean, readable typography like Outfit and Inter.
